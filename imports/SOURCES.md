# OmniNX source collection

This directory records source repositories inspected for the OmniNX server build.

## Sources

- PretendoNetwork/nex-go — NEX networking/server foundation reference.
- PretendoNetwork/nex-protocols-go — NEX protocol definitions/reference.
- Woody-NX/NiklasCFW_Pack — NiklasCFW package source/reference; only server-relevant, legally redistributable source will be integrated.

## Integration rule

Repositories are reviewed repository-by-repository. We do not blindly merge firmware, keys, proprietary Nintendo files, or unrelated binaries into OmniNX. Original licenses and attribution are preserved when source is incorporated.
