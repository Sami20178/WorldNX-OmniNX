# OmniNX+ Daily Agent Plan

## Agent-1 Plan – täglicher Ablauf

Jeden Tag wird dieser Ablauf ausgeführt:

1. Pretendo Network prüfen:
   - Pretendo Progress prüfen.
   - Relevante neue Pretendo-Repositories, Commits und Änderungen feststellen.
   - Pro Tag mindestens 1 relevantes Pretendo-Repository auswählen.

2. NiklasCFW prüfen:
   - Relevante neue Repositories, Commits und Releases prüfen.
   - Pro Tag mindestens 1 relevantes NiklasCFW-Repository auswählen.

3. WorldNX-OmniNX prüfen:
   - Prüfen, welche der neuen Informationen für OmniNX+ relevant sind.
   - Den bestehenden Original-OmniNX-Look und die WorldNX-Basis beibehalten.
   - Keine fremden Firmware-/Payload-Binaries automatisch übernehmen.

4. Tagesplan dokumentieren:
   - Datum des Laufs.
   - 1 Pretendo-Repository.
   - 1 NiklasCFW-Repository.
   - Gefundene Änderungen.
   - Mögliche OmniNX+-Integration.
   - Status.

5. GitHub:
   - Den Tagesplan automatisch in diesem Repository speichern.
   - Die tägliche Aktualisierung als Commit dokumentieren.
   - Keine echten Shop-/Server-URLs oder Hosts direkt in den Quellcode übernehmen.

## Heute

Der heutige Lauf wird durch GitHub Actions automatisch erzeugt und in diesem Repository dokumentiert.
