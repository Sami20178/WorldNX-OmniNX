# WorldNX-OmniNX

Das ist OmniNX Upgrade und OmniNX weitere Entwicklung.

## Projekt

WorldNX-OmniNX führt die OmniNX-Basis weiter und erweitert sie schrittweise.

## Dokumentation

Die ausführliche Projektdokumentation befindet sich im [Wiki](wiki/README.md).

Dort werden Projektübersicht, Struktur, Tagesplanung und Entwicklungsregeln dokumentiert.

## Repository-Struktur

- `sources/` – Quellen
- `server/` – Serverbestandteile
- `imports/` – importierte Bestandteile
- `daily-plans/` – Tagespläne
- `.github/` – GitHub-Konfiguration

## Entwicklung

Änderungen werden passend zur bestehenden Projektbasis vorgenommen und nachvollziehbar dokumentiert.
